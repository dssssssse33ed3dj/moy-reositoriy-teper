 Задача 1. Максимальная серия 

Уточняющие вопросы к условию:
1. Может ли цель goal быть отрицательным числом, и как в таком случае обрабатывать шаги?
2.  Как функция должна реагировать, если в списке step` переданы не те типы данных? (допустим на вход подаются только int)
3. Корректно ли, что при пустом списке steps и любом значении goal ответом всегда будет 0? (Да, согласно примеру в ТЗ).

Собственные примеры «вход → ожидаемый ответ»:
1. steps =, goal = 10000 -> Ожидаемый ответ: 3
2. steps =, goal = 10000 -> Ожидаемый ответ: 2
3. steps =, goal = 10000 -> Ожидаемый ответ: 0

Инвариант цикла:
На конце i-й итерации: max_streak_len хранит длину самой длинной непрерывной серии дней, достигших цели, среди уже проверенных элементов steps[0...i], а
current_streak хранит длину текущей непрерывной серии, заканчивающейся в день i.

Первая версия решения:
def max_streak(steps: list[int], goal: int = 10_000) -> int:
    max_streak_len = 0
    current_streak = 0
    for day_steps in steps:
        if day_steps >= goal:
            current_streak += 1
            if current_streak > max_streak_len:
                max_streak_len = current_streak
        else:
            current_streak = 0
    return max_streak_len

Задача 3. Удаление на месте 

Уточняющие вопросы к условию:
1. Какую сигнатуру имеет функция is_spam и что она принимает (индекс, текст комментария или сам объект комментария)? (Предполагаем функцию, принимающую элемент списка).
2. Должна ли функция возвращать новый список, измененный старый, или изменять список in-place и возвращать None? (Из названия предполагаем изменение исходного списка in-place и возврат None)
3. Важен ли порядок оставшихся комментариев после удаления спама? (но обычно порядок важен - предполагаем сохранение относительного порядка).

Собственные примеры вход → ожидаемый ответ:
1. comments = ["good", "http://spam.com", "nice"] -> Ожидаемый ответ: 2, список: ["good", "nice"]
2. comments = ["https://spam.org", "http://spam.ru"] -> Ожидаемый ответ: 0, список: []
3. comments = [] -> Ожидаемый ответ: 0, список: []

Инвариант цикла:
На конце i-й итерации (при проходе по индексам):
Все элементы исходного списка comments[0...i], которые не являются спамом, сдвинуты в начало списка comments[0...k-1] с 
сохранением относительного порядка, где k это количество одобренных (не спам) комментариев, обнаруженных к текущему моменту

Первая версия решения:
def remove_spam(comments: list[str]) -> int:
    write_index = 0
    for read_index in range(len(comments)):
        if not is_spam(comments[read_index]):
            comments[write_index] = comments[read_index]
            write_index += 1
    while len(comments) > write_index:
        comments.pop()
    return write_index
