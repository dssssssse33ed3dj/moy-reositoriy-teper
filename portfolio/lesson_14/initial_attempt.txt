Задача 1. Палиндром с пропуском символов

Вопросы к условию (до кода):
1. Какие символы - буквы или ещё цифры?
2. Регистр важен или сравниваем без учёта?
3. Как быть с пустой строкой и строкой без букв, это палиндро или нет?

Перебор и его сложность:
Сделать копию остортированной строки и сравнить с перевёрнутой - O(n) время, O(n) память на копию.
Указатели с двух концов без копии - O(n) время, O(1) память.

Примеры (вход → ожидаемый ответ):
1. '' → True
2. 'а' → True
3. '!!!' → True
4. 'А роза' → True (если регистр не важен и пробелы/знаки игнорируются)
5. '12321' → True (цифры тоже значимы)
6. 'аб' → False

Задача 2. Почти-палиндром

Вопросы к условию (до кода):
1. Что вернуть, если строка уже палиндром?
2. Какой индекс возвращать при двух различияхЖ -1 или None?

Перебор и его сложность:
Удалить каждый символ по очереди и проверить остаток на палиндром - O(n^2) время, O(n) память.
Два указателя + одна проверка остатка при первом различии - O(n) время, O(1) память.

Примеры:
1. 'аба' → уже палиндром, удалять не надо 
2. 'аб' → удалить последний символ 'б' → 'а', индекс 1
3. 'абва' → два различия → нельзя (индекс -1)
4. '' → True / -1 (пустая строка уже палиндром)
