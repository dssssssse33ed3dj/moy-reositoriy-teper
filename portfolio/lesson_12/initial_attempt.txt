Задача 1. Объединение интервалов

Вопросы к условию (до кода):
1. Что возвращать при пустом входе, пустой список? 
2. Склеивать ли касающиеся интервалы [1, 2]?
3. Можно ли изменить исходный список? 

Перебор и его сложность:
Каждый интервал сравнивается со всеми остальными вложенным циклом. Сложность по времени: O(n^2), по памяти: O(n) для нового списка.

Примеры (вход → ожидаемый ответ), среди них пустой список, один интервал, касание и вложенный интервал:
1. [] → []
2. [[1, 3]] → [[1, 3]]
3. [[1, 2], [2, 3]] → [[1, 3]]
4. [[1, 5], [2, 4]] → [[1, 5]]
5. [[1, 2], [1, 2]] → [[1, 2]]

Задача 2. Встречи без конфликтов

Вопросы к условию (до кода):
1. Является ли касание [1, 2] и [2, 3] конфликтом? 
2. Что возвращать для пустого списка встреч? 

Перебор и его сложность:
Проверка каждого интервала с каждым на пересечение через двойной цикл. Сложность по времени: O(n^2), по памяти: O(1).

Примеры, среди них касание, повтор встречи и конфликт только в последней паре:
1. [[1, 2], [2, 3]] → True
2. [1, 3], [[1, 3]] → False
3. [[1, 2], [3, 4], [4, 5]] → True
4. [[1, 2], [3, 4], [3, 5]] → False
