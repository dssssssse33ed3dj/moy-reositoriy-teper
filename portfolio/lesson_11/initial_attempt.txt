Задача 1. Сервис сумм на диапазонах (range_sums)

Вопросы к условию:
1. Как обрабатывать некорректные индексы в запросах? 
2. Что возвращать при пустом списке queries? 

Наивный перебор и его сложность:
- На каждый запрос считать сумму циклом `sum(nums[l:r])`. Сложность: O(q * n), где q — число запросов, n - длина массива. При больших данных это вызовет Time Limit Exceeded.

Примеры (вход → ожидаемый ответ):
1. nums =, queries = [(0, 3)] → [6] (запрос на весь массив)
2. nums =, queries = [(1, 1)] → [0] (запрос-точка, l == r)
3. nums = [], queries = [(0, 0)] → [0] (пустой список, запрос 0..0)
4. nums =, queries = [(0, 2)] → ValueError (неверный запрос, r > len)
5. nums =, queries = [(2, 1)] → ValueError (неверный запрос, l > r)

Задача 2. Равновесный индекс (pivot_index)

Вопросы к условию (до кода):
1. Что возвращать для пустого списка nums? 
2. Включается ли сам элемент nums[i] в левую или правую сумму? 

Примеры:
1. nums = [] → -1 (пустой список)
2. nums = [1, 7, 3, 6, 5, 6] → 3 (индекс 3, суммы слева и справа равны 11)
3. nums = [1, 2, 3] → -1 (равновесия нет)
4. nums = [2, 1, -1] → 0 (индекс 0, сумма слева 0, сумма справа 0)
