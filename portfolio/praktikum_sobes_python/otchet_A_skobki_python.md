## 4. Код и границы (50:00–1:01:20)

Какая операция добавляет открывающуюся скобку в стек: open_brackets_stack.append(bracket)

Какая операция снимает последнюю открытую скобку: stack.pop()

Что должно произойти, если закрывающаяся скобка пришла при пустом стеке: вернуть False, иначе pop вернет ошибку IndexError

Почему проверки должны быть в двух местах: при встрече закрывающейся скобки
и после окончания строки: Проверка внутри цикла ловит лишние закрывающие скобки, а проверка пустоты стека в конце ловит незакрытые открывающие скобки

**⏸ Пауза перед итогом.** Назовите сложность по времени и памяти. Что такое
`n` в этой оценке: По времени - O(n), по памяти - O(n) в худшем случае, n - длина входной строки.
